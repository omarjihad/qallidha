# قلّدها 🎤

لعبة تقليد الأصوات داخل **Telegram Mini App** — على نفس فكرة Mimic Party:
صوت يشتغل للكل ← الكل يقلّده بنفس اللحظة (فرصة وحدة) ← التسجيلات تنعاد قدام الكل ← درجة من 100 ← عجلة حظ بين الجولات فيها نقاط ومضاعفات وتخريب.

مستضافة كاملة على **Cloudflare مجانًا بدون بطاقة**. الشرح الكامل للنشر: [`DEPLOY-CLOUDFLARE.md`](DEPLOY-CLOUDFLARE.md).

## شنو فيها

- مسرح ثلاثي الأبعاد (three.js): أرضية خشب، مايك بالنص، 8 شخصيات كرتونية بتظليل toon وحدود سوداء.
- كروت اللاعبين فوق، أسمائهم فوق روسهم، وأيقونة السماعة على اللي يغني.
- شريط الموجة: الأصل رمادي، تسجيلك أزرق، والمؤشر الأحمر.
- «حاول تقلّدها!» ← 3، 2، 1 ← «يلا!» ← تسجيل جماعي.
- الدرجة «X / 100» لكل تسجيل، والشخصية تمشي للمايك وفمها يتحرك مع الصوت. مضاعف العجلة ونقاطها تنضاف للرقم قدّام الكل (40/100 ← +10 ← 50/100).
- عجلة: ‎+5 / +10 / +20 / ×1.5 / ×2 (تنحسب بالجولة الجاية) / 🔄 تبديل الأصوات / صدى / سنجاب / تقطيع / تشويش / ضرطة 💩 — والتخريب والتبديل ينكشفون وقت الإعادة بس.
- لحد 5 لاعبين، 4 جولات، تحدي فردي، ترتيب عام، تفاعلات إيموجي.
- **🎲 لعب عشوائي** ويا ناس ما تعرفهم: غرف عامة تنجمع لوحدها، عد تنازلي وتبدي بدون مضيف، وبعد النهاية لعبة جديدة باللي باقين.
- **العرض (Landscape) تلقائي** بنفس طريقة «رقعة»: اللعبة تتدوّر بنفسها، مو الجهاز.
- أصوات الميمز تنضاف من البوت (فويس/صوت/فيديو + صورة)، و18 صوت مدمج للبداية، ومكتبة 113 ميم تنزل لوحدها (بيها جمل أنمي: ون بيس، ناروتو، بليتش، بلاك كلوفر، دراغون بول، جوجو…).
- **لفل 1–100** حسب النقاط الكلية، وعملة **🎤 مايكات** من كل لعبة.
- **متجر**: 16 شخصية، قبعات ونظارات تنلبس على الشخصية، و8 مسارح — بالمايكات أو بالإعلانات، وتجربة 24 ساعة.
- **رويال باس** شهري: 50 لفل مجاني، و100 لفل مميز بـ99 ⭐ (دفع نجوم تيليجرام من داخل اللعبة).
- **شراء بالنجوم**: باقات مايكات، لفلات باس، ومميز + 10 لفلات.
- **إعدادات ⚙️**: العربية والإنكليزية والروسية (تلقائي حسب تيليجرام)، جودة الرسوم، حد الفريمات وعدّاد FPS، الصوت، الاهتزاز، ووضع المايك.
- **إشعار للأدمن بكل لاعب جديد** (اسمه، يوزره، الآيدي، لغته، منين دخل) — يتطفى ويشتغل بـ`/newusers`.
- **إعلانات AdsGram** (اختيارية): إعلان بنهاية اللعبة + إعلانات بمكافأة (مايكات، صندوق يومي، فتح أغراض، خبرة باس، مضاعفة).

## التقييم

`public/js/scorer.js` — يقارن **اللحن** (حدّة YIN مع نقل المقام) و**الإيقاع** و**البدايات**، ويتجاهل نبرة الصوت.
محاذاة زمنية DTW. يشتغل بجهاز اللاعب (مثل الأصلية)، و**كل جهاز يقيّم كل التسجيلات والسيرفر ياخذ الوسيط** — فلاعب واحد يغش ما يأثر.

## الهيكل

```
src/            العامل (Worker) + البوت + الكائنات الدائمة
  worker.js     التوجيه، API، بروكسي ملفات تيليجرام
  room.js       غرفة اللعب (المراحل، التوقيت، التسجيلات، العجلة)
  hub.js        الترتيب + الأصوات المضافة + الغرف العامة (العشوائي) + إشعار اللاعبين الجدد + ربط الـwebhook
  economy.js    اللفلات، المايكات، المتجر، الباس، الإعلانات بمكافأة
  pass.js       فاتورة الباس بالنجوم
  telegram.js   أوامر البوت وإضافة الأصوات والدفع
  auth.js       التحقق من initData
public/         الواجهة (بدون build)
  js/main.js    الإقلاع والقائمة
  js/game.js    متحكّم اللعبة
  js/catalog.js الأغراض والأسعار والباس (مشترك ويا السيرفر)
  js/meta.js    المتجر والباس والمكافآت
  js/ads.js     AdsGram
  js/settings.js / settingsPanel.js  الإعدادات
  js/i18n.js + js/lang/ru.js, en.js  الترجمة (النص العربي هو المفتاح)، lang/detect.js يختار اللغة
  js/stage.js   المسرح والشخصيات
  js/audio.js   المايك والتشغيل
  js/scorer.js  التقييم
  js/effects.js التخريبات
  js/tg.js      تيليجرام + التدوير للعرض
tools/          أدوات واختبارات (ما تنرفع للسيرفر)
```

## تشغيل محلي (اختياري)

```bash
npm install
cp .dev.vars.example .dev.vars
npx wrangler dev
```

اختبارات: `node tools/test-scorer.mjs` (المقيّم) — `node tools/sim.mjs 3` (لعبة كاملة بدون واجهة) — `node tools/eco-test.mjs` (الاقتصاد والدفع، يحتاج `node tools/mock-tg.mjs`) — `node tools/ui-meta.mjs` (المتجر والباس والإعدادات واللغة بالمتصفح) — `node tools/stars-test.mjs` (الشراء بالنجوم) — `node tools/wheel-test.mjs` (نقاط العجلة والتبديل) — `node tools/quick-test.mjs` و`node tools/ui-quick.mjs` (اللعب العشوائي) — `node tools/join-test.mjs` (إشعار اللاعب الجديد ولغة البوت) — `UI_LANG=en node tools/ui-lang.mjs` (الواجهة بالإنكليزي/الروسي) — `node tools/ui-slider.mjs` (شرائط الصوت باللمس) — `node tools/i18n-keys.mjs` (أي نص ما مترجم).
