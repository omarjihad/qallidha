# قلّدها 🎤

لعبة تقليد الأصوات داخل **Telegram Mini App** — على نفس فكرة Mimic Party:
صوت يشتغل للكل ← الكل يقلّده بنفس اللحظة (فرصة وحدة) ← التسجيلات تنعاد قدام الكل ← درجة من 100 ← عجلة حظ بين الجولات فيها نقاط ومضاعفات وتخريب.

مستضافة كاملة على **Cloudflare مجانًا بدون بطاقة**. الشرح الكامل للنشر: [`DEPLOY-CLOUDFLARE.md`](DEPLOY-CLOUDFLARE.md).

## شنو فيها

- مسرح ثلاثي الأبعاد (three.js): أرضية خشب، مايك بالنص، 8 شخصيات كرتونية بتظليل toon وحدود سوداء.
- كروت اللاعبين فوق، أسمائهم فوق روسهم، وأيقونة السماعة على اللي يغني.
- اللاعبين **يدخلون يمشون من اليسار** ويوكفون بالصف أول ما تدخل الغرفة (وكل ما يدخل واحد جديد).
- **🗣️ دردشة صوتية بالغرفة**: تحچون ويا بعض، والمايك **ينسد لوحده وقت المثال والتسجيل** (مثل الأصلية). زر 🎙️ يسكّر مايكك، ودوسة على كارت لاعب تكتمه عندك.
- شريط الموجة: الأصل رمادي، تسجيلك أزرق، والمؤشر الأحمر.
- «حاول تقلّدها!» ← 3، 2، 1 ← «يلا!» ← تسجيل جماعي.
- الدرجة «X / 100» لكل تسجيل، والشخصية تمشي للمايك وفمها يتحرك مع الصوت. مضاعف العجلة ونقاطها تنضاف للرقم قدّام الكل (40/100 ← +10 ← 50/100).
- عجلة: ‎+5 / +10 / +20 / ×1.5 / ×2 (تنحسب بالجولة الجاية) / 🔄 تبديل الأصوات / صدى / سنجاب / تقطيع / تشويش / ضرطة 💩 — والتخريب والتبديل ينكشفون وقت الإعادة بس.
- لحد 5 لاعبين، 4 جولات، تحدي فردي، ترتيب عام، تفاعلات إيموجي.
- **🎲 لعب عشوائي**: قائمة **الغرف العامة** الموجودة (المضيف، اللاعبين، الحالة) تختار منها، أو **➕ إنشاء غرفة عامة**، أو **⚡ دخول سريع**. عد تنازلي وتبدي بدون مضيف، وبعد النهاية لعبة جديدة باللي باقين.
- **🎤 العب ويا ربعك** = غرفة **خاصة**: ما تبين بالقائمة وتنفتح بالكود بس.
- **ترتيب الإعادة عشوائي** كل جولة (مو أول واحد دخل دائمًا أول).
- **العرض (Landscape) تلقائي** بنفس طريقة «رقعة»: اللعبة تتدوّر بنفسها، مو الجهاز.
- أصوات الميمز تنضاف من البوت (فويس/صوت/فيديو + صورة)، و18 صوت مدمج للبداية، ومكتبة **240 ميم** تنزل لوحدها: أنمي (ون بيس، ناروتو، بليتش…)، مسلسلات وميمز عربية (باب الحارة وغيرها)، أفلام ومسلسلات أجنبية (I am the danger…)، وألعاب وكرتون.
- **🎙️ أصوات اللاعبين**: أي لاعب يدز للبوت فويس/فيديو/ملف صوت (أقل من 15 ثانية) واسمه ← يوصل للأدمن ← **قبول**: ينضاف للعبة ويا صورة اللاعب واسمه، وياخذ **50 🎤 و50 خبرة** — **رفض**: البوت يطلب السبب ويوصّله للاعب.
- **لفل 1–100** حسب النقاط الكلية، وعملة **🎤 مايكات** من كل لعبة. **الضغط على اسمك وصورتك** يفتح لوحة اللفلات: كل اللفلات وجائزة كل لفل وشلون تصعد وشكد باقيلك.
- **متجر**: 16 شخصية، قبعات ونظارات تنلبس على الشخصية (تصاميم مجسّمة: نظارات بإطار وعدسات وذراعين، نظارة نجوم، شوارب مبرومة، لثام نينجا، مونوكل بسلسلة، قرون معكوفة…)، و8 مسارح — بالمايكات أو بالإعلانات، وتجربة 24 ساعة.
- **رويال باس** شهري: 50 لفل مجاني، و100 لفل مميز بـ99 ⭐ (دفع نجوم تيليجرام من داخل اللعبة).
- **شراء بالنجوم**: باقات مايكات، لفلات باس، ومميز + 10 لفلات.
- **إعدادات ⚙️**: العربية والإنكليزية والروسية (تلقائي حسب تيليجرام)، جودة الرسوم، حد الفريمات وعدّاد FPS، الصوت، الاهتزاز، ووضع المايك.
- **إشعار للأدمن بكل لاعب جديد** (اسمه، يوزره، الآيدي، لغته، منين دخل) — يتطفى ويشتغل بـ`/newusers`.
- **🔥 مسابقة المتصدرين** (أسبوعية): أول 3 يربحون **نجوم تيليجرام** (الافتراضي 150 / 75 / 50 ⭐). كارت بالقائمة بعدّاد حي (الوقت المتبقي والجوائز)، وتبويب «🔥 المسابقة» بالمتصدرين، والنقاط تنحسب بس من الألعاب اللي بيها **لاعبين تيليجرام اثنين أو أكثر** (عشوائي أو ويا ربعك — اللعب وحدك ما ينحسب). من تخلص: رسالة للأدمن بالفائزين، ورسالة ونافذة «🎉 فزت» لكل فائز. الجوائز يدفعها الأدمن بإيده (هدية نجوم) ويأشّر «✅ انطيته».
- **🛠️ لوحة المطوّر داخل اللعبة** (للأدمن بس — زر 🛠️ بالقائمة): كل أوامر البوت بواجهة وحدة + **📢 نشر المسابقة** (إذاعة لكل اللاعبين بلغة كل واحد: «🔥 بدأت» أول مرة، وإذا منشورة من قبل كليشة تذكير بالوقت المتبقي والمتصدرين هسه) + **🎁 الهدايا**: مايكات، لفل، سكنات وأغراض (أو كلها)، الرويال باس المميز، ولفلات باس — واللاعب توصله رسالة بالبوت ونافذة «🎁 وصلتك هدية» باللعبة.
- **🛠️ لوحة المطوّر بالبوت** (`/admin`): 📊 إحصائيات (لاعبين، جدد، نشطين، ألعاب، نجوم، أصوات، غرف) — 📢 إذاعة لكل اللاعبين (أي نوع رسالة، بتأكيد وتقرير) — 🚫 حظر بالآيدي أو بتحويل رسالة (من اللعبة والبوت) — 🎙️ الأصوات المقترحة — ⚙️ وضع الصيانة، إشعار الجدد، **ريست التوب** (المتصدرين بس، المشتريات واللفلات ما تنمس)، وإعادة ربط البوت.
- **إعلانات AdsGram** (اختيارية): إعلان بنهاية اللعبة + إعلانات بمكافأة (مايكات، صندوق يومي، فتح أغراض، خبرة باس، مضاعفة).

## التقييم

`public/js/scorer.js` — يقارن **اللحن** (حدّة YIN مع نقل المقام) و**الإيقاع** و**البدايات**، ويتجاهل نبرة الصوت.
محاذاة زمنية DTW. يشتغل بجهاز اللاعب (مثل الأصلية)، و**كل جهاز يقيّم كل التسجيلات والسيرفر ياخذ الوسيط** — فلاعب واحد يغش ما يأثر.

## الهيكل

```
src/            العامل (Worker) + البوت + الكائنات الدائمة
  worker.js     التوجيه، API، بروكسي ملفات تيليجرام
  room.js       غرفة اللعب (المراحل، التوقيت، التسجيلات، العجلة)
  hub.js        الترتيب + الأصوات (المكتبة والمضافة والمقترحة) + الغرف العامة + مسابقة المتصدرين + صندوق اللاعب (هدايا وفوز) + لوحة المطوّر (حظر، صيانة، إذاعة، إحصائيات) + ربط الـwebhook
  contest.js    نصوص المسابقة للبوت (بداية، تذكير، فائزين) بلغة كل لاعب
  admin.js      لوحة المطوّر باللعبة (/api/admin — الأدمن بس)
  gifts.js      هدايا الأدمن (مايكات، لفل، أغراض، باس)
  economy.js    اللفلات، المايكات، المتجر، الباس، الإعلانات بمكافأة
  pass.js       فاتورة الباس بالنجوم
  telegram.js   أوامر البوت، الأصوات (الأدمن واللاعبين)، لوحة المطوّر، والدفع
  auth.js       التحقق من initData
public/         الواجهة (بدون build)
  js/main.js    الإقلاع والقائمة
  js/admin.js + css/admin.css  لوحة المطوّر باللعبة (تنحمّل للأدمن بس)
  js/contestUi.js  كارت المسابقة، المتصدرين، ونوافذ الهدية والفوز
  js/contest.js الجوائز والمدة وتنسيق الوقت المتبقي (مشترك ويا السيرفر)
  js/game.js    متحكّم اللعبة
  js/catalog.js الأغراض والأسعار والباس (مشترك ويا السيرفر)
  js/meta.js    المتجر والباس والمكافآت
  js/ads.js     AdsGram
  js/settings.js / settingsPanel.js  الإعدادات
  js/i18n.js + js/lang/ru.js, en.js  الترجمة (النص العربي هو المفتاح)، lang/detect.js يختار اللغة
  js/stage.js   المسرح والشخصيات
  js/audio.js   المايك والتشغيل
  js/voice.js + js/adpcm.js  الدردشة الصوتية (8kHz ADPCM عبر اتصال الغرفة)
  js/scorer.js  التقييم
  js/effects.js التخريبات
  js/tg.js      تيليجرام + التدوير للعرض
tools/          أدوات واختبارات (ما تنرفع للسيرفر)
```

## تشغيل محلي (اختياري)

```bash
npm install
cp .dev.vars.example .dev.vars
npx wrangler dev
```
